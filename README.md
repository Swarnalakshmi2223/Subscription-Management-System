# Subscription Management System

Odoo Hackathon project for Brightloop Software, built with the MERN stack.

## Structure
- `backend/`: Node.js, Express and MongoDB API
- `frontend/`: React, Vite and Material UI
- `docs/`: Architecture and SRS

## Run locally
1. Backend: `cd backend`, copy `.env.example` to `.env`, then `npm install` and `npm run dev`
2. Frontend: `cd frontend`, then `npm install` and `npm run dev`
